= Change the view order of shelves in SANtricity System Manager
:icons: font
:imagesdir: ../media/

[.lead]
You can change the order of shelves displayed on the Hardware page to match the physical order of shelves in a cabinet.

.Steps

. From the left panel, select menu:Hardware[Controllers and components].
. Select the drop-down list for a shelf, and then select *Change order* to rearrange the order of shelves shown on the Hardware page.
